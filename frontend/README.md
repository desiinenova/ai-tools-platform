# AI Tools Platform — Frontend

Next.js 15 (App Router) frontend. See the [root README](../README.md) for installation, running the project, the role system, and how to use the platform.

Quick reference for frontend-specific work:

```bash
docker exec ai-tools-frontend npx tsc --noEmit   # type-check
docker exec ai-tools-frontend npx eslint .        # lint
docker exec ai-tools-frontend npm install <pkg>   # add a dependency
```
