# AI Tools Platform — Backend

Laravel 12 API. See the [root README](../README.md) for installation, running the project, the role system, and how to use the platform.

Quick reference for backend-specific work:

```bash
docker exec ai-tools-backend php artisan test       # run the test suite
docker exec ai-tools-backend php artisan migrate    # apply new migrations
docker exec ai-tools-backend composer require <pkg> # add a dependency
```
